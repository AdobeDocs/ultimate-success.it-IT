# Operazionalizzazione di Adobe Data Insights Agent in CJA

Scopri come trasformare Adobe Data Insights Agent in un flusso di lavoro pratico e quotidiano all’interno di Customer Journey Analytics. Questa sessione mostra come i team possono utilizzare il linguaggio naturale per accelerare l’analisi, abilitare informazioni self-service e ridurre l’affidamento sul reporting manuale. Se desideri migliorare il time-to-insight e ridimensionare il processo decisionale basato sui dati in tutta l’organizzazione, questo è un imperativo.
