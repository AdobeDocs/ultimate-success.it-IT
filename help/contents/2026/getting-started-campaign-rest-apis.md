# Jumpstart la tua integrazione: guida introduttiva alle API REST di Campaign

Le API REST di Campaign offrono un modo semplificato per creare interazioni preziose con i clienti, collegando i momenti di coinvolgimento con le azioni di marketing o servizio. Questa sessione fa parte della serie Ultimate Success ed è progettata per aiutarti a comprendere e utilizzare queste API in modo efficace.

## Concetti chiave

- Scopri come tradurre un caso di utilizzo in una piccola storia di integrazione testabile.
- Scopri dove le API creano valore e dove potrebbero non essere lo strumento giusto.
- Ottieni informazioni sulla creazione di forme di richiesta, l’impostazione di guardrail e la definizione di percorsi di produzione.

## Panoramica

Le API REST di Adobe Campaign non sono solo strumenti; sono un gateway per la creazione di interazioni cliente immediate e personalizzate. Queste API ti consentono di:

- Attiva azioni specifiche in base ai momenti del cliente, ad esempio l’invio di e-mail di conferma o l’aggiornamento delle preferenze dell’utente.
- Integrazione perfetta con altre applicazioni, inclusi Adobe e sistemi esterni.
- Supporta casi d’uso a bassa latenza e basati su eventi, ad esempio notifiche al carrello abbandonate, e-mail di benvenuto e conferme transazionali.

## Agenda

1. **Panoramica aziendale:**
   - Concetti strategici delle API REST.
   - Identificazione dei momenti del cliente per l’utilizzo dell’API.
2. **Informazioni tecniche:**
   - Configurazione e autenticazione degli endpoint API.
   - Configurazione dell’autenticazione IMS e dei progetti della console per sviluppatori.
   - Informazioni sulla selezione degli endpoint e sulla personalizzazione del payload.
3. **Demo:**
   - Configurazione dei tipi di evento e dei modelli in Adobe Campaign.
   - Utilizzo di Postman per le chiamate API SOAP e REST.
   - Esempi pratici di chiamate API e dei loro risultati.

## Chi deve partecipare

Questa sessione è ideale per:

- **Amministratori** che cercano di ottimizzare le integrazioni di sistema e i flussi di lavoro.
- **Sviluppatori** che cercano di implementare le API REST di Campaign o di risolverne i problemi.
- **Utenti** interessati a comprendere le funzionalità delle API REST di Adobe Campaign per migliorare le strategie di marketing digitale.
